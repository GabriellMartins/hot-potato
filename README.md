# 🥔 Hot Potato

Plugin de **Hot Potato (Batata Quente)** desenvolvido para o **Dev Battle Kingdom**.

O desafio consistia em criar um plugin funcional de Minecraft em apenas **1 hora**, sem utilizar ferramentas externas.

> **1 hora. 1 plugin. 1 batata. 🥔**

---

## ⚔️ Dev Battle Kingdom

O **Dev Battle Kingdom** foi um desafio de desenvolvimento onde os participantes tiveram apenas **60 minutos** para desenvolver um plugin de **Hot Potato**.

A proposta era colocar à prova não apenas a programação, mas também a capacidade de pensar, tomar decisões e resolver problemas sob pressão.

### 📜 Regras

* ⏱️ Apenas **1 hora** para desenvolver o plugin
* 🥔 O plugin deveria ser de **Hot Potato / Batata Quente**
* 🚫 Sem utilização de **IA**
* 🚫 Sem utilização de **APIs externas**
* 🚫 Sem utilização de **Spigots customizados**
* ✅ Tudo deveria ser desenvolvido durante o desafio

---

## 🥔 Sobre o plugin

O **Hot Potato** é um minigame baseado na clássica brincadeira de batata quente.

Um jogador recebe a batata e precisa passá-la para outro jogador antes que o tempo termine.

Quando o tempo acaba, o jogador que estiver com a batata é eliminado.

A partida continua até restar apenas um jogador.

### 🎮 Principais mecânicas

* 🥔 Sistema de Hot Potato
* 🔄 Transferência da batata entre jogadores
* ⏱️ Sistema de tempo
* 💀 Eliminação
* 🏆 Sistema de vencedor
* 🎮 Gerenciamento da partida
* ⏳ Contagem regressiva
